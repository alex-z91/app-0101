# Rifa Solidária — Riandro

Landing page da campanha solidária para aquisição de uma cadeira de rodas adaptada para corrida.

- Prêmio: tênis Actvitta Speed Carbon
- Cartela: números de 01 a 100
- Valor: R$ 20,00 por número
- Meta bruta: R$ 2.000,00
- Pix: Edna Magalhães Uchoa

## Implantação

Subdomínio planejado: rifasolidaria.alexcoder.space.

O sistema de reservas e pagamentos deve permanecer **desativado** até validação do regulamento e das exigências legais. Não salve dados de participantes ou comprovantes no filesystem efêmero de hospedagem gratuita.

## Infraestrutura

Python + Flask (Render). Use disco persistente ou banco externo e armazenamento privado de comprovantes antes de habilitar a operação comercial.
